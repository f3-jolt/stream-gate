Advancement Message Template

            
When this league has a current season with games scheduled, the message is built from the database using this template. Tokens: {pingRole}, {weekLabel}, {season}, {userGames}, {cpuGames}, {advanceDate}. The advance deadline auto-fills to 36h out (48h when there are user games). Leave blank to use the default format.

Build Schedule

            
Pick a team on the left to load its schedule. For each week set the opponent (type to search — blank = BYE), home/away, and the user flag, then Save. Saving reloads so opponents reflect across teams — save before switching teams. Weeks 15–19 (CCW, BW1, BW2, CFP Semi, NC) are the postseason and may rematch regular-season opponents.
